# Мой персональный ассистент

Персональный стратегический планировщик с голосовым вводом и ИИ-ядром.

---

## Что умеет

| Функция | Описание |
|---------|----------|
| 🌅 Утро | Цитата дня + список задач с цветами + предупреждение если нет отдыха |
| 🌙 Вечер | AI-итог дня + автоперенос невыполненного + план на завтра |
| 🎤 Голос | Говоришь задачу или идею — Claude парсит и добавляет куда надо |
| 💡 Идеи | Банк идей с датой напоминания — ничего не теряется |
| 🌍 Горизонт | Большие намерения без дат ("осенью отпуск", "в 2026 первые продажи") |
| 📁 Проекты | Match Point / Taylor Studio / Боты / Личное |

---

## Быстрый старт

### 1. Переменные окружения

```bash
cp .env.example .env
```

Открой `.env` и вставь ключ:
```
ANTHROPIC_API_KEY=sk-ant-...
```

Ключ получить: https://console.anthropic.com

### 2. Установка зависимостей

```bash
cd backend
pip install -r requirements.txt
```

### 3. Запуск

```bash
uvicorn main:app --reload
```

### 4. Открыть в браузере

```
http://localhost:8000
```

База данных `assistant.db` создаётся автоматически при первом запуске.
Стартовые проекты (Match Point, Taylor Studio, Боты, Личное) уже добавлены.

## Голосовые команды (примеры)

```
"Добавь встречу с Ахмедом в пятницу в три часа"
→ задача типа work, пятница, 15:00

"Есть идея про MICE направление, напомни через неделю"
→ идея в банк с датой напоминания

"Запланируй прогулку сегодня вечером"
→ задача типа rest

"Надо найти бухгалтера"
→ задача типа work на сегодня
```

Голос работает в Chrome и Edge (ограничение Web Speech API).

## API

Все эндпоинты на `http://localhost:8000/api/`

```
GET  /api/morning              — данные для утреннего экрана
GET  /api/evening              — итог дня + перенос задач
GET  /api/tasks?for_date=      — задачи на дату
POST /api/tasks                — создать задачу
PUT  /api/tasks/{id}/toggle    — выполнено/не выполнено
DELETE /api/tasks/{id}         — удалить
POST /api/voice                — голосовой ввод
GET  /api/projects             — список проектов
GET  /api/ideas                — банк идей
POST /api/ideas                — добавить идею
PUT  /api/ideas/{id}/archive   — архивировать
GET  /api/horizon              — горизонт жизни
POST /api/horizon              — добавить намерение
DELETE /api/horizon/{id}       — удалить
```

Интерактивная документация: `http://localhost:8000/docs`

## Деплой (опционально)

Для запуска в интернете (Railway):

```bash
# Установить Railway CLI
npm install -g @railway/cli

# Логин и деплой
railway login
railway init
railway up
```

Не забудь добавить `ANTHROPIC_API_KEY` в переменные окружения Railway.
