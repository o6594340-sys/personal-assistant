# Брифинг: Личный стратегический ассистент
*Версия 1.0 — май 2026*
*Основан на discovery-интервью + исследовании рынка*

---

## Суть продукта

Персональный веб-планировщик с голосовым вводом и ИИ-ядром для предпринимателя с несколькими проектами и насыщенной жизнью. Один экран где видна вся жизнь целиком — проекты, цели, день, отдых — и которым можно управлять голосом или текстом. Не просто органайзер, а стратегический партнёр, который помогает не только планировать, но и двигаться к целям без выгорания.

---

## Пользователь

**Ольга** — предприниматель, мама, со множеством проектов одновременно.

**Характер:**
- Гиперактивная, быстро думает, быстро принимает решения
- Генерирует много идей — это ценность, но они ломают план
- Откладывает скучное (бухгалтерия, рутина) — нужен мягкий пинок
- Не любит разбираться в сложных инструментах — если не понятно за 3 секунды, закрывает
- Лучшее что работало раньше: простой список с галочками в телефоне

**Главный риск 2026:**
Снова уйти в тотальный перегруз. Отдых и забота о себе — стратегический блок, не бонус.

**Проекты:**
1. Match Point — основной бизнес (representation / B2B туризм)
2. Taylor Studio — новый DMC (иностранные туристы + MICE)
3. Боты — на паузе, переосмысливается
4. Личное — здоровье, женственность, отдых, ремонт

---

## Проблема

Системы ломаются потому что:
- Новые идеи накапливаются и сносят текущий план
- Неприятные задачи откладываются до аврала
- Отдых вытесняется работой (может 16 часов не выходить из дома)
- Сложные инструменты (Notion) закрываются сразу

---

## Иерархия планирования

```
Горизонт жизни    →  большие намерения без дат ("осенью отпуск", "системная забота о теле")
Проекты и цели    →  Taylor Studio, Match Point, Боты, Личное
Неделя            →  фокус и приоритеты на 7 дней
День              →  конкретные задачи + блоки на отдых
```

## Функциональные требования

### P0 — без этого не запускаем

---

#### Утренний экран (открывает сама, без пуша)

- **Цитата дня** — вверху страницы, крупно
  - От разносторонних личностей: писатели, художники, философы, учёные, предприниматели
  - Не только про бизнес — про жизнь, женственность, красоту, смысл
  - Цель: зарядить + обогатить эрудицию (читать некогда, цитата — мини-культурный ритуал)
  - Генерируется через Claude API каждое утро

- **Задачи на сегодня** — список с чекбоксами
  - Цветовое кодирование по типу: 🔵 работа / 🟢 личное / 🟡 отдых / 🟣 рост/обучение
  - Блоки на отдых/прогулку встроены автоматически
  - Если день забит только рабочими задачами — визуальный сигнал "нет времени для себя"

- **Буферные блоки** — автоматически между задачами, нельзя удалить

---

#### Вечерний ритуал (открывает сама, вечером)

- Что сделано сегодня — честная сводка
  - Сделала мало (3 из 8): нейтрально, без осуждения, перенос без вины
  - Сделала много (7 из 8): заслуженная похвала, не искусственная
  - Похвала пропорциональна реальному результату
- Невыполненное переносится на завтра автоматически
- Что запланировано на завтра — превью следующего дня

---

#### Голосовой ввод

- Надиктовать задачу: *"добавь косметолога на пятницу в 15:00"*
- Надиктовать идею с датой: *"есть идея X, напомни обсудить через неделю"*
- Попросить разбить цель: *"хочу получить лицензию к июлю, что делать"*
- Работает с телефона и компьютера (Web Speech API)
- ИИ парсит речь и создаёт структурированную запись

---

#### Отложенные напоминания (единственный вид пуш-уведомлений)

- Только для идей и намерений с конкретной датой возврата
- Пример: *"Ты хотела обсудить идею про арабские агентства — поговорим?"*
- Пользователь сама назначает дату при добавлении идеи

---

#### Горизонт жизни

- Раздел глобальных намерений без конкретных дат
- Примеры: "осенью — отпуск", "в 2026 — системная забота о теле", "до конца года — первые продажи Taylor Studio"
- Запрос: *"какие у меня глобальные планы?"* → полный список
- Стартовый контекст: загружен из basic info.docx
- При еженедельном планировании ассистент может связать горизонт с текущими задачами

---

#### Проекты и цели

- Список проектов: Match Point / Taylor Studio / Боты / Личное
- У каждого — цели и задачи
- Задачи из проектов попадают в расписание
- Видна связь: задача → проект → цель на год → горизонт жизни

---

#### Банк идей

- Все голосом пойманные идеи лежат отдельно — не теряются, не ломают план
- На еженедельном планировании: *"Вот твои новые идеи — берём что-то в план?"*

---

#### Google Calendar синхронизация

- Создавать события в календаре из приложения
- Читать существующие события (не создавать конфликты)

---

### P1 — важно, но после запуска

- **Разбивка цели на задачи через Claude API** — говоришь цель, получаешь шаги с предложением вставить в план
- **Энергетическое планирование** — тяжёлые задачи в продуктивные часы, рутина в спад
- **Статистика недели** — сколько сделано по каждому проекту, сколько блоков на отдых
- **Еженедельный ретроспектив** — ИИ задаёт вопрос "что мешало на этой неделе?"

---

### P2 — если захочется потом

- Копирование задачи для делегирования ассистенту (одна кнопка)
- Визуальный таймлайн дня (как в Structured)
- Статистика по кварталам

---

## Чего НЕТ в этом продукте

- Глубокая стратегия по проектам → для этого Claude отдельно
- Управление командой / совместный доступ
- CRM / финансы / документы
- Сложный onboarding
- Notion-уровень гибкости и сложности

## Как выглядит один день

```
Утро    → открыла → цитата дня (Симона де Бовуар / Стив Джобс / Рильке)
                  → список задач с цветами + автоблок "прогулка 30 мин"

День    → голосом добавила идею → легла в банк идей
        → голосом: "добавь встречу с Ахмедом в пятницу"

Вечер   → открыла → "Сделала 6 из 7. Серьёзный день, молодец.
                       Одну задачу перенесла на завтра.
                       Завтра у тебя: [список] + блок на себя"

Пуш     → в нужный день: "Ты хотела обсудить идею про MICE направление"

Воскр.  → "Вот твои идеи за неделю: [список]. Берём что-то в план?"
```

## Конкурентное преимущество

Ни один продукт на рынке не совмещает:
- Голосовой ввод
- Горизонт жизни / глобальные намерения
- Вечерний ритуал с честной обратной связью
- Обязательные блоки на отдых как приоритет
- Цитата дня как утренний ритуал

Sunsama — лучший вечерний ритуал, но нет голоса и нет горизонта жизни ($25/мес).
Наш продукт: всё это + сделан под конкретного пользователя.

## Технический стек

| Компонент | Решение |
|---|---|
| Frontend | PWA (React или HTML+JS+CSS) |
| Backend | Python (FastAPI) |
| База данных | PostgreSQL (или SQLite для старта) |
| Голосовой ввод | Web Speech API (бесплатно, в браузере) |
| ИИ-ядро | Claude API (claude-sonnet-4-6) |
| Пуш-уведомления | Web Push API |
| Календарь | Google Calendar API |
| Хостинг | Railway / Render |
| Язык интерфейса | Только русский |

---

## Принципы интерфейса

1. Понятно за 3 секунды — иначе закроет
2. Мобильный телефон = основное устройство
3. Простой список + возможность провалиться в детали
4. Не перегружать экран — минимум элементов
5. Цвет как навигация, не как украшение
6. Голос как основной способ добавления (не форма)

## MVP — что делаем первым

**Объём:** 3–4 недели разработки

**Входит в MVP:**
- Утренний экран: цитата + задачи с цветовым кодированием
- Вечерний ритуал: итоги + план на завтра
- Голосовой ввод задач
- Горизонт жизни (просмотр + добавление)
- Проекты (4 штуки, базово)
- Банк идей
- Google Calendar синхронизация (создание событий)
- Отложенные пуш-напоминания

**НЕ входит в MVP (P1/P2):**
- Разбивка целей через ИИ
- Энергетическое планирование
- Еженедельный ретроспектив с ИИ
- Визуальный таймлайн
- Статистика
