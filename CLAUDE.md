Персональный стратегический ассистент для Ольги — предпринимателя, мамы, с несколькими проектами одновременно.
Это не просто планировщик — это инструмент который помогает достигать целей, не сгорая.

## Claude API (claude-sonnet-4-6)

Три AI-функции в `backend/main.py`:

1. **`get_or_create_quote(today)`** — цитата дня, кэшируется в БД
   - Разные личности: писатели, художники, философы, учёные, предприниматели
   - Не только про бизнес — про жизнь, красоту, женственность, смысл
   - JSON: `{"text": "...", "author": "Имя, кто это"}`

2. **`ai_evening_summary(done, undone)`** — вечерний итог
   - 80%+ выполнено → заслуженная спокойная похвала
   - 50–79% → нейтрально, по-деловому
   - <50% → поддерживающе, без осуждения
   - НЕЛЬЗЯ: "Вау!", "Молодец!", "Супер!" — звучит фальшиво

3. **`ai_parse_voice(text, today)`** — парсинг голосового ввода
   - Определяет: задача или идея
   - Извлекает: дату, время, тип задачи
   - JSON: `{"type": "task|idea", "title": "...", "task_type": "work|personal|rest|growth", "date": "...", "time_start": "...", "remind_at": "..."}`

## Дизайн-принципы

- Понятно за 3 секунды
- Mobile-first (iPhone — основное устройство)
- Цвет как навигация, не как украшение
- Голос — основной способ ввода
- Язык: только русский

**Цвета интерфейса:**
- Background: #F7F6F3
- Cards: #FFFFFF
- Primary text: #1A1A2E
- Muted: #6B7280
- Gold accent: #C8A96E

## Что НЕ входит в этот продукт

- Глубокая стратегия по проектам → для этого Claude отдельно
- Управление командой / совместный доступ
- CRM / финансы / документы
- Notion-уровень сложности

## Запуск

```bash

cp .env.example .env

# 2. Установить зависимости
cd backend
pip install -r requirements.txt

# 3. Запустить
uvicorn main:app --reload

# 4. Открыть
# http://localhost:8000
```
